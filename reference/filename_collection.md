# Collection of a harmonized file

Collection of a harmonized file

## Usage

``` r
filename_collection(filename)
```

## Arguments

- filename:

  character: file name

## Value

character in upper case, e.g. "GMD", taken from a file name like
"COL_2010_GEIH_V04_M_V01_A_GMD_ALL.dta"; NULL for any other file name.
