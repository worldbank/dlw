# get data calls when more than one option.

get data calls when more than one option.

## Usage

``` r
gmd_calls(ctl, country_code, ...)
```

## Arguments

- ctl:

  data.table from \[dlw_server_inventory\]

- country_code:

  ISO3

## Value

list of possible calls
