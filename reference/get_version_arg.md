# Version argument of the API request

Builds the value of the \`para1\` request parameter from \`vermast\` and
\`veralt\` (e.g., "V12_M", "V12_M_V01_A"), unless \`para1\` is already
given.

## Usage

``` r
get_version_arg(dots)
```

## Arguments

- dots:

  list of additional arguments of \[dlw_get_data\]

## Value

character or NULL
