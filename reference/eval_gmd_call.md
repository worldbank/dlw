# evaluate GMD call

evaluate GMD call

## Usage

``` r
eval_gmd_call(calls, verbose = getOption("dlw.verbose"))
```

## Arguments

- calls:

  calls from \[gmd_calls\]

- verbose:

  logical: whether to display info

## Value

evaluation
